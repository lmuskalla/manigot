## What

If I select a job, it shows the current stage, I can read the .md files and I can launch respective agents. However, this FORCES the user to adhere to the ideal workflow which in many cases will not be what the user wants to do. E.g. I might want something done quick, so I'll create a job, write the brief and two tasks by hand and then let the developer have a go and immediately set it do done. I should be able to do this from the TUI.

So 2 things:
- make it possible to launch whatever agents in whatever stage
- make it possible to set a job to done
